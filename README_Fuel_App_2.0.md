# Fuel App 2.0 — wersja bazowa

Ta wersja jest odtworzona z dostarczonego projektu Fuel App bez dodawania nowych funkcjonalności.

Zakres zmian względem źródłowego projektu został ograniczony do:
- nazwy katalogu projektu `Fuel_App_2.0`,
- przywrócenia brakującej zależności `excel`, wymaganej przez istniejący kod importu/eksportu XLSX.

Nie zmieniano logiki aplikacji, interfejsu ani istniejących funkcji.
